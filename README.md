# CloudStream 3-Web Template

Tiga provider terpisah: Web1, Web2, Web3.

Ganti `mainUrl` pada masing-masing provider dengan URL situs yang memang kamu punya hak untuk integrasikan.

Template ini sengaja tidak menyertakan extractor sumber video pihak ketiga. Fungsi `search()`, `load()`, dan `loadLinks()` perlu disesuaikan dengan API/HTML situs milikmu.

Dokumentasi resmi:
https://recloudstream.github.io/csdocs/devs/gettingstarted/
